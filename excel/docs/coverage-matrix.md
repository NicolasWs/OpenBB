# Coverage matrix: how each openbb-api endpoint lands in Excel

Generated by `npm run matrix` from `fixtures/openapi.json`, recorded from the nicogeek server (openbb-core 2.0.1). The machine-readable version is `coverage-matrix.json` (one row per endpoint).

**1085 endpoints**, of which 914 land directly in cells, and 125 get a typed `=OBB.<ROUTE>()` function (standard routers). Every cell-landing endpoint is also reachable through `=OBB.QUERY()`.

## By shape

| Shape | Endpoints | Lands as | Meaning |
|---|---:|---|---|
| `table` | 676 | spill | list of records with declared columns |
| `table-dynamic` | 197 | spill | list of records whose columns are known only at runtime (e.g. Fed `pivot_wide` tables) |
| `range-input` | 104 | range-input | POST analytics taking a data range as input (not yet in Linear) |
| `helper` | 37 | none | parameter option lists used by the task pane, not data |
| `document` | 25 | single-cell | text, markdown or HTML, in one cell (truncated at 32,767 chars) or as a file |
| `file` | 16 | file | downloads and document viewers, saved from the task pane (M2) |
| `chart` | 14 | chart | chart-only routes returning Plotly JSON (M2) |
| `nested` | 9 | spill | records with object or list fields, flattened to `a.b` columns or JSON text |
| `record` | 4 | spill | one object, spilled as key/value rows |
| `scalar` | 3 | single-cell | one number or string in one cell |

## Known runtime gaps on the recorded server

- `GET coverage/command_model` returns 422 (server bug), so the catalog is built from `openapi.json`.
- nasdaq historical prices (equity, ETF) return 204 for every request; cboe historical works.
- Keyed providers (fred, bls, eia, cftc, congress_gov) return 400 "Missing credential" until keys are set on the server.
